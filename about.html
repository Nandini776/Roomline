How Roomline gets to an answer

Roomline wraps a scikit-learn pipeline trained on NYC Airbnb listings. Nothing about the prediction is hand-tuned per request — the same four stages run every time.

The dataset

The model is trained on the NYC Airbnb Open Data listings set — tens of thousands of real listings across the Bronx, Brooklyn, Manhattan, Queens and Staten Island, each labelled with its actual room type.

The pipeline

Numeric fields (price, coordinates, review counts…) are median-imputed and standard-scaled. Categorical fields (borough, neighbourhood) are one-hot encoded, with unseen neighbourhoods handled gracefully rather than rejected. A random forest of 50 trees, weighted to correct for how much more common entire-home listings are, makes the final call.

The rarest class — with fewer examples to learn from, predictions here carry the most uncertainty.

A note on limitations

This is a statistical estimate, not a fact about the listing. It reflects patterns in historical data — it can be wrong, and it can reflect biases already present in that data (for instance, which boroughs happen to have more of one room type). Treat the output as a starting point, not a verdict.
